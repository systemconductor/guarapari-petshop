# Maré & Mimo Petshop

Scroll-driven petshop website template for a fictional neighborhood petshop in Guarapari, Espírito Santo, Brazil.

## Run locally

```bash
npx serve .
```

Then open the printed local URL.

## Stack

- Semantic HTML
- Vanilla CSS
- ScrollCraft runtime (`scrollcraft.js`)
- No build system or framework

## Notes

The brand, address, WhatsApp number, and copy are placeholders for template testing. Replace them before production use. The page uses four ScrollCraft device families: pinned scenes, flow reveals, horizontal service rail, and magnetic CTAs.
